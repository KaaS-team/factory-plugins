# factory-plugins

Agent presets, runtimes and notifiers for KaaS Factory.

**Status: in development.** The repo holds the licence and this note. Nothing here is published or installable yet.

## What it will be

Plugins that plug a coding agent, a runtime or a notifier into the factory without changing its core. They start after the plugin interface lands in KaaS Factory.
